# フニクラ実験シミュレーター

アントニ・ガウディが用いた**逆さ吊り実験（フニクラ実験）**の設計手法を再現するインタラクティブWebアプリケーションです。

## 概要

ガウディは天井から紐や鎖を吊り下げ、重りを付けて自然に形成される懸垂線（カテナリー曲線）を観察し、それを上下反転させることで理想的なアーチ構造を導き出しました。このアプリでは、その一連のプロセスをブラウザ上で体験できます。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要）。

### 設計フェーズ

1. **固定点追加** — 天井（上部の赤い破線）付近をクリックして固定点を配置
2. **チェーン追加** — 2つの点を順にクリックしてチェーン（鎖）を接続
   - 既存のチェーン上をクリックすると、その位置に接続点が自動生成され、チェーンが分割されます
3. **重り追加** — チェーン上をクリックして重りを配置（重力で曲線が変化）
4. **選択/移動** — 固定点をドラッグで移動。プロパティパネルでチェーンの長さや重りの質量を調整

### 構造表示フェーズ

- **反転表示**: 上下を反転して、懸垂線がアーチ構造に変わる様子を確認
- **アニメーション**: スムーズなアニメーション付きの反転

### キーボードショートカット

| キー | 操作 |
|------|------|
| `1` | 固定点追加モード |
| `2` | チェーン追加モード |
| `3` | 重り追加モード |
| `4` | 選択/移動モード |
| `F` | 反転表示の切り替え |
| `Delete` | 選択中の点を削除 |
| `Escape` | 選択解除 |

## 技術構成

| ファイル | 内容 |
|----------|------|
| `index.html` | アプリのHTML構造 |
| `style.css` | ダークテーマUI |
| `catenary.js` | 物理エンジン（Verlet積分＋距離拘束） |
| `app.js` | インタラクション・レンダリング・状態管理 |

### 物理シミュレーション

チェーンの形状計算にはVerlet積分を使用しています。チェーンを多数の粒子に分割し、重力の適用と距離拘束の反復解決を繰り返すことで、重りの質量に応じた自然な懸垂線を再現します。

## 背景：ガウディの逆さ吊り実験

石やレンガは圧縮力には強いが引張力には弱いという性質があります。重力で自然に形成された懸垂線を反転させると、すべての力が圧縮方向に変換され、フライング・バットレスなどの外部支持なしに自立する構造が得られます。ガウディはこの原理を用いてコロニア・グエル教会やサグラダ・ファミリアを設計しました。
